BoxArea GIS System

Geographic Information System application for interactive polygon rendering and municipal boundary layer inspection across Dauphin County fire departments and coverage areas.

Launch Live App ↗ / View GitHub Repo ↗

Overview

BoxArea GIS System is designed for Dauphin County fire departments and coverage areas to provide interactive polygon rendering and inspection of municipal boundary layers.

Features

  • Interactive polygon rendering and inspection of municipal boundary layers.
  • Built with the architecture and capability to show fire station locations and dispatch run card layers (omitted from the public deployment due to operational security concerns).
  • Permission-Based Access Control (PBAC) can be enabled for restricted or role-specific access.
  • FastAPI backend.

Stack

FastAPI, Leaflet GIS, GeoJSON, Python, Docker.
